# 미니게임 디자인 토큰 (2026-11-13 개편)

컨셉은 **게임기 선반**이에요. 게임마다 고유 색이 하나 있고, 버튼과 카드는 눌리는 느낌이 나는 두툼한 모양이에요. 그 밖의 요소는 조용하게 둬요.
설치된 폰트만 써요(Pretendard Variable → Pretendard → Apple 시스템 → Apple SD Gothic Neo → Malgun Gothic → Noto Sans KR). 웹폰트·CDN은 쓰지 않아요.

### 게임 색 (`data-game`)

`body`나 허브 카드에 `data-game`을 달면 `--accent`가 바뀌고, 파생 색(`--accent-strong`, `--accent-edge`, `--accent-soft`, `--accent-ink`, `--focus`)이 그 자리에서 다시 계산돼요. 모두 흰 글자와 4.5:1 이상이에요.

| 게임 | 색 | 게임 | 색 |
| --- | --- | --- | --- |
| 스도쿠 `sudoku` | `#2458d6` | 핀 뽑기 `pin-pull` | `#b45309` |
| 2048 | `#c2410c` | 물 분류 `water-sort` | `#0e7490` |
| 지뢰찾기 `minesweeper` | `#15803d` | 나사 풀기 `screw-puzzle` | `#475569` |
| 슬라이드 퍼즐 `slide` | `#0f766e` | 주차장 탈출 `parking-jam` | `#c62828` |
| 카드 짝맞추기 `memory` | `#be185d` | 꼬인 줄 풀기 `untangle` | `#a21caf` |
| 워들 `wordle` | `#6d28d9` | 초성 퀴즈 `chosung` | `#a15c07` |

새 게임을 만들면 `assets/style.css`의 게임 색 목록에 한 줄 추가하고, 허브 카드에도 같은 `data-game`을 달아요.

## 모양

- **버튼 `.btn`**: 2px 테두리, 반경 14px, 아래 3px 단색 두께(`--edge`). 누르면 3px 내려가며 두께가 사라져요. 주 동작 `.primary`는 게임 색 면에 흰 글자, 두께는 `--accent-edge`예요.
- **켜진 토글** `[aria-pressed="true"]`: 게임 색 옅은 면 + 게임 색 테두리 + 눌린 상태. 주 동작 버튼과 헷갈리지 않게 꽉 채우지 않아요.
- **비활성**: 점선 테두리, 보조 면, `--muted` 글자. 투명도로 흐리게 만들지 않아요.
- **세그먼트 `.seg`**: 선택된 칸만 게임 색으로 채워요. 허브 탭은 `--brand`로 채워요.
- **허브 카드**: 가로형 카트리지. 왼쪽 60px 게임 색 블록(이모지), 오른쪽 이름(1.12rem/900)과 설명(0.92rem, 줄임 없이 줄바꿈). 아래 4px 두께, 누르면 내려가요. 모바일 1열, 640px 이상 2열.
- **게임 헤더**: 아래에 4px 게임 색 줄. 뒤로 가기는 테두리 있는 작은 버튼 모양이에요.
- **반경**: 다이얼로그·패널 20px, 카드 18px, 버튼·세그먼트 14~16px, 칩은 캡슐.

## 글자

- 허브 제목 `미니게임`: clamp(2.1rem, 9vw, 3rem), 900, 자간 -0.055em, 왼쪽 정렬.
- 게임 제목 1.2rem/900. 본문 1rem, 줄 높이 1.55. 안내 `.hint` 0.9rem `--text-2`.
- 라벨 최소 0.78rem. 그보다 작은 글자는 쓰지 않아요.
- 숫자 표시(`.stat .value`)는 1.45rem/900, `tabular-nums`.

## 움직임

- 누름: 0.08초. 다이얼로그 등장 0.3초. 장식용 자동 움직임은 넣지 않아요.
- `prefers-reduced-motion`에서는 애니메이션과 눌림 이동을 꺼요.

스도쿠의 구획·오답, 워들의 초록/노랑/회색, 지뢰찾기 숫자별 색, 2048의 숫자별 색 단계, 퍼즐 게임의 그림(시험관·자동차·나사판)은 그대로 둬요.
