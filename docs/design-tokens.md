# Icebreaker 디자인 토큰

참조: `/workspace/icebreaker-ref/index.html`의 인라인 CSS. 참조 파일은 수정하지 않았어요.

- 라이트: 배경 `#f4f5f9`, 카드 `#ffffff`, 보조 면 `#f7f8fb`, 경계 `#e4e6ee`, 본문 `#171923`, 보조 글 `#606579`예요.
- 강조: 인디고 `#4f46e5`, 호버 `#4338ca`, 연한 면 `#eef0ff`, 글자 `#3730a3`예요. 배경 위쪽에는 인디고 방사형 빛을 얹어요.
- 참조에는 다크 모드가 없어요. 같은 색조로 배경 `#14151f`, 카드 `#1e202e`, 보조 면 `#252838`, 본문 `#f1f2f8`, 보조 글 `#adb2c8`, 강조 글 `#c4bfff`를 구성했어요.
- 폰트는 Pretendard Variable → Pretendard → Apple 시스템 폰트 → Apple SD Gothic Neo → Malgun Gothic → Noto Sans KR → 시스템 sans-serif 순서예요. 설치된 폰트만 사용하고 웹폰트나 CDN을 추가하지 않아요. 제목은 800, 자간은 -0.03em, 본문 줄 높이는 1.5~1.65예요.
- 카드는 반경 22px, 1px 경계, 3px 인디고 상단 선과 얕은 이중 그림자를 사용해요. 버튼·탭 바는 14px, 탭 내부는 10px, 칩은 캡슐 모양이에요. 선택한 탭은 카드색 면과 진한 글자, 선택한 칩은 본문색 면과 반전 글자예요.
- 탭 간격과 안쪽 여백은 4px, 칩 간격은 6px, 버튼 간격은 8px, 카드 간격은 14px예요. 허브 바깥 여백은 데스크톱 48px/24px, 모바일 28px/16px예요. 모든 일반 조작 버튼의 최소 크기 44px를 유지해요.
- 움직임은 0.15~0.2초 전환과 `cubic-bezier(.2,.7,.2,1)`, 팝업은 8px 아래에서 0.38초 등장해요. 움직임 줄이기 설정에서는 애니메이션과 호버 이동을 줄여요.

스도쿠의 구획·오답, 워들의 초록/노랑/회색, 지뢰찾기의 숫자별 색, 2048의 따뜻한 숫자별 색 단계는 유지해요. 게임 로직·문구와 접근성 다이얼로그 코드는 수정하지 않았어요.
